# 🐍 Desenvolvimento Rápido em Python

Este repositório contém os projetos e exercícios práticos desenvolvidos durante as aulas de **Desenvolvimento Rápido em Python (RAD)**. O foco é a criação de aplicações desktop robustas, integração com banco de dados e boas práticas de programação.

## 🚀 Tecnologias Utilizadas
*   **Linguagem:** Python 3
*   **Interface Gráfica:** Tkinter e ttk
*   **Banco de Dados:** SQLite3
*   **ORM:** SQLAlchemy (básico)
*   **Testes:** Unittest
*   **Outros:** Manipulação de arquivos (I/O), Expressões Regulares (Regex), Dataclasses e POO.

## 📂 Estrutura das Aulas
O projeto foi dividido em módulos para facilitar o acompanhamento da evolução:

*   **Aula 1:** Manipulação de arquivos e diretórios.
*   **Aula 2:** Manipulação de Strings e Expressões Regulares (Regex).
*   **Aula 3:** Estruturas de dados avançadas (`collections`) e Tratamento de Erros.
*   **Aula 4:** Arquivos binários e Serialização com `pickle`.
*   **Aula 5:** Introdução ao Banco de Dados com SQLAlchemy (CRUD).
*   **Aula 6 e 7:** Sistema de Cadastro modularizado (SQLite, Logs e POO).
*   **Aula 8 e 9:** Laboratório de Interface Gráfica (Tkinter) com 21 exemplos de widgets e layouts.
*   **Aula 10:** **Projeto Integrador** - Sistema de Cadastro completo com Interface Gráfica, SQLite e Testes Unitários.

1. Clone o repositório.
2. Navegue até a pasta `aula_10_aplicacoes_python/sistema_cadastro`.
